1) 어제 지출 $1,929(직전 7일 평균 대비 −1%) · 설치 1,512 · CPI $1.28(+14%) · D0 ROAS 2.8%(−9%), 수익 중 광고 비중 50%. 추적 누락 범위를 빼면 CPI $1.15 2) 🔴 즉시 확인: 메타 iOS(META_A+APP_IOS_T1) KR·US 10/04~10/06 3일 연속 설치 0 — 지출 KR $233·US $349, 클릭은 정상(F01·F02). 이 캠페인 예산 제안은 보류했다 3) 🟠 소재: 피로 2개 — MV03_tower_climb_15s(BR, CTR −35%, frequency 3.9), GV02_gear_merge_15s(구글 T1, IPM −44%) / 확장 후보 1개 — MP01_totem_tap_playable(IPM 캠페인 중앙값의 1.6배) 4) 💰 예산 제안: 증액 1건 / 감액 1건, 순변동 +$5/일, 보류 4건. 구글은 10월 예산 소진 속도가 빠르다(월말 예상 $27,613, +23%) 5) 오늘 할 일: 1. MMP에서 메타 iOS 연동·SKAN 포스트백 수신 확인(F01·F02) 2. B01(META_A+APP_AOS_T3 $250→$200), B02(META_A+APP_AOS_T1 $350→$405) 승인 여부 결정 3.
