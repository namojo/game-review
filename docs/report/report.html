1. 요약

과제별 결론

과제 결론 PoC
1. 리뷰 대응 자동화 바로 도입한다. 절감 시간은 작지만(연 약 62시간), 답변 품질과 속도가 크게 바뀐다. 지금은 60일 동안 답변이 13일에만 몰려 등록되고, 답변까지 중앙값 3.3일(답변 뒤 리뷰를 고친 10건 제외)이 걸린다[실측] 검수 웹서비스 https://namojo.github.io/game-review/ (리뷰 378건, 13개 언어)
2. 주간 이벤트 제작 자동화 바로 도입한다. 셋 중 절감 시간이 가장 크다(연 약 234~806시간). 디자인 1~2일 작업 중 키아트 생성과 13개 언어 배너 합성이 몇 분으로 줄어든다. 사람은 주제 승인, 수치 결정, 최종 검수를 맡는다[고객+가정, 4.2절] W44 「형님들의 할로윈 호박 사냥」 키트(13개 언어, 배너 39장, 스토어 시트)
3. 광고 운영·분석 자동화 데이터 접근 권한을 받은 뒤 3단계로 도입한다. 매일 1시간 이상 걸리던 작업이 15분 안팎으로 줄어든다(연 약 188~208시간)[가정]. 효과의 핵심은 추적 누락·CPI 급등·소재 피로를 하루 안에 찾는 것이다 가상 데이터 분석 샘플. 심은 문제 7건 탐지, 오탐 0, 5줄 일일 리포트

기대 효과(시간)

과제 연간 절감 근거
1. 리뷰 대응 약 62시간 하루 6.3건[실측] × 365 × (2분[고객] − 검수 0.387분[가정]) ÷ 60
2. 주간 이벤트 약 234~806시간 주 4.5~15.5시간 × 52. 운영 1~2시간[고객] → 0.5시간[가정], 디자인 8~16시간[고객] → 2~4시간[가정]
3. 광고 운영 약 188~208시간 (60분[고객] − 10~15분[가정]) × 250일[가정] ÷ 60
합계 약 483~1,076시간(FTE 약 0.25~0.56명분) FTE 1명 = 연 1,920시간[가정]. 인건비 환산은 시간당 비용을 받은 뒤 계산한다

바로 결정할 일 3가지

  1. 10/9(금)까지 할로윈 이벤트 스토어 제출 여부. App Store 사전 노출(10/12부터)과 Play 피처링 요청 마감(10/12)을 지키려면 이번 주에 제출해야 한다. 그 전에 [기획 확인 필요] 15건 가운데 두 가지를 먼저 정한다. #4 할로윈 주말 48시간 광고 없는 버프를 승인할지(B안: 하루 N회로 축소), #13 러시아 스토어 노출을 접속 장애 해결 뒤로 미룰지다.
  2. 리뷰 답변 등록용 자격 증명 2종 발급과 운영 방식 승인. Play 서비스 계정('리뷰 답변' 권한), App Store Connect API 키가 필요하다. 운영 방식은 A안을 권한다. 검수 화면을 claude.ai Artifact로 올리고 매일 예약 실행으로 초안을 만든다. 같은 날 미답변 결제 P1(1만원 결제 후 0원 표시) 1건을 처리한다.
  3. 광고 계정 읽기 권한과 데이터 현황 공유. 실제 매체, MMP, 미디에이션, 월 예산, 사내 메신저(C1~C16)를 알려 주면 과제 3의 1단계(노코드 리포트, 2~3주)를 바로 시작한다.

2. 진단

2.1 고객이 알려 준 현재 방식(원문 인용)

과제 현재 방식 담당 어려움 검토 방향 소요
1. 리뷰 대응 담당자가 리뷰를 직접 확인하고 번역·답변 작성(미리 작성해 놓은 답변 사용) 운영 매일 대응이 가장 좋지만 다른 업무 일정에 따라 며칠간의 리뷰를 한 번에 처리하는 경우가 많음 리뷰 수집 → 유형 분류 → 번역 → 답변 초안 생성 → 담당자 검수 → 답변 등록 리뷰 1개당 2분
2. 주간 이벤트 매주 이벤트 주제 선정, 문구 작성, 번역, 이미지 제작 및 스토어 등록을 각각 진행 운영·디자인 매주 유사한 제작 과정 반복, 국가별 문구·이미지 제작에 많은 시간 주제 선정 → 제목·내용 작성 → 이미지 제작 → 다국어 번역 → 스토어 이벤트 등록 운영 매주 1~2시간, 디자인 1~2일
3. 광고 운영 담당자가 광고 데이터를 직접 확인하고 분석·운영 마케팅 국가·캠페인·소재별 데이터 확인과 반복 분석 데이터 수집 → 성과 분석 → 문제점 파악 → 예산·다음 액션 제안 → 리포트 작성 매일 1시간 이상

4.1 과제 1 — 리뷰 대응

항목 값 출처
일평균 리뷰 수 6.3건 [실측] stats.per_day_avg
현재 1건 처리 시간 2분 [고객]
자동화 뒤 검수 시간 맞춤 0.5분 / 템플릿 0.2분 [가정] 읽기·승인만
템플릿 비율 37.6%(142/378) [실측]
가중 평균 검수 시간 0.387분 = 0.376 × 0.2 + 0.624 × 0.5 계산
현재 연간 76.7시간 = 6.3 × 365 × 2 ÷ 60 계산
자동화 뒤 연간 14.8시간 = 6.3 × 365 × 0.387 ÷ 60 계산
연간 절감 약 62시간(61.8) 계산
Claude API 비용 월 약 2~3달러 = 월 189건 × Haiku 4.5(입력 3,000·출력 400 토큰, $1/$5 per MTok) + 맞춤 118건 × Sonnet 5.5(입력 3,500·출력 400, $2/$10) ≈ $0.95 + $1.30 [가정] 건당 토큰. 단가는 2026-09-25 Anthropic 공시

절감 시간은 작다. 효과는 품질(맞춤 답변), 속도(P1 24시간, 지금 중앙값 3.3일), 인사이트(부서별 주간 전달), 번역 대기 제거에서 난다.

4.2 과제 2 — 주간 이벤트

항목 값 출처
현재 운영 주 1~2시간 [고객]
현재 디자인 주 1~2일 = 8~16시간 [고객]
