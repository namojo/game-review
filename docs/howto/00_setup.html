00. 사전 준비 — 한 번만 하면 된다

이 문서대로 준비하면, 고객사 PC에서 이 프로젝트의 하네스(에이전트 7 · 스킬 6)를 그대로 실행할 수 있다. macOS 기준이다. Windows는 WSL을 권한다.

준비물 어디에 쓰나 필수
Claude Code + Claude 구독 계정(Pro·Max·Team 등) 하네스 실행 전체 필수
하네스 플러그인(harness@harness-marketplace) 하네스를 새로 만들거나 고칠 때(/harness:harness, /harness:evolve) 새로 만들 때
Python 3.10+ 가상환경(.venv) 리뷰 수집, 배너 합성, 화면 검사 필수
codex CLI + ChatGPT 계정 로그인 과제 2 키아트 생성(image_generation) 과제 2
GitHub CLI(gh) 로그인 과제 1 웹서비스 배포(GitHub Pages) 과제 1 배포

1. Claude Code 설치와 로그인

# 설치(둘 중 하나)
curl -fsSL https://claude.ai/install.sh | bash
# 또는
npm install -g @anthropic-ai/claude-code

claude --version

프로젝트 폴더에서 claude 를 실행하면 처음에 로그인 화면이 나온다. Claude 구독 계정으로 로그인한다. 나중에 계정을 바꾸려면 Claude Code 안에서 /login 을 입력한다.

2. 프로젝트 폴더 만들기

하네스는 폴더 단위로 동작한다. Claude Code는 실행한 폴더의 CLAUDE.md 와 .claude/ 를 읽는다.

mkdir -p ~/work/thunder && cd ~/work/thunder
git init            # 버전 관리를 권장한다(하네스 변경 이력 추적)

3. 이 프로젝트의 하네스를 고객사 저장소로 복사하기

컨설팅 결과물 폴더(이 저장소)에서 아래 세 가지를 복사한다. 하네스를 새로 만들 필요 없이 바로 쓸 수 있다.

SRC=/path/to/thunder        # 컨설팅 결과물 폴더
DST=~/work/thunder          # 고객사 작업 폴더

cp    "$SRC/CLAUDE.md" "$DST/"                 # 하네스 목표·호출 조건·변경 이력
cp -R "$SRC/.claude"   "$DST/"                 # agents/ 7개, skills/ 6개(스크립트·참고 문서 포함)
mkdir -p "$DST/_workspace/00_input"
cp -R "$SRC/_workspace/00_input/game_art" "$DST/_workspace/00_input/"   # 키아트 화풍 참고 이미지

# 선택: 지난 결과를 이어서 쓰려면(리뷰 누적 데이터, 이벤트 캘린더)
cp -R "$SRC/game-review"   "$DST/"             # 리뷰 검수 웹서비스 + data/reviews.json
cp -R "$SRC/deliverables"  "$DST/"             # 이벤트 캘린더·키트, 광고 샘플, 보고서

복사한 뒤의 구조:

thunder/
├── CLAUDE.md
├── .claude/
│   ├── agents/   review-ops-analyst · review-service-engineer · liveops-event-planner
│   │             event-visual-designer · ads-growth-strategist · consulting-qa · consulting-report-editor
│   └── skills/   thunder-ai-consulting(오케스트레이터) · review-response-ops · review-web-service
│                 weekly-event-production · ad-performance-automation · consulting-report
├── _workspace/00_input/game_art/   icon · header · shot1~4 (화풍 참고)
├── game-review/                    (선택) 리뷰 웹서비스
└── deliverables/                   (선택) 지난 산출물

.claude/settings.local.json 처럼 개인 PC 경로·권한이 든 파일이 있으면 복사하지 않는다.

4. 하네스 플러그인 설치 — 하네스를 새로 만들거나 고칠 때만

복사한 하네스를 실행만 할 때는 필요 없다. 하네스를 새로 만들거나(01_build_harness_prompts.md) 회고·개선할 때(/harness:evolve) 설치한다. Claude Code 안에서 입력한다.

/plugin marketplace add revfactory/harness
/plugin install harness@harness-marketplace

/plugin 만 입력하면 화면 메뉴에서 마켓플레이스(revfactory/harness)를 추가하고 harness 를 고를 수도 있다. 설치 뒤 Claude Code를 다시 시작하면 /harness:harness, /harness:evolve 를 쓸 수 있다.

5. Python 가상환경

프로젝트 폴더 바로 아래에 .venv 를 만든다. 스킬 문서와 스크립트가 ./.venv/bin/python 경로를 쓴다.

python3 -m venv --system-site-packages .venv && ./.venv/bin/pip install google-play-scraper playwright && ./.venv/bin/playwright install chromium
패키지 쓰는 곳
google-play-scraper 리뷰 수집(fetch_reviews.py)
playwright + chromium 배너 합성(compose_banner.py 가 HTML을 렌더링해 PNG로 찍는다), 웹서비스 화면 검사
Pillow 이미지 크기 확인·미리보기. --system-site-packages 로 시스템 것을 쓰고, 없으면 ./.venv/bin/pip install pillow

6. codex CLI — 과제 2 키아트 생성

키아트는 OpenAI codex CLI의 image_generation 도구로 만든다. ChatGPT 계정으로 로그인하므로 별도 OpenAI API 키가 필요 없다.

npm install -g @openai/codex          # 설치
codex login                           # 브라우저에서 ChatGPT 계정으로 로그인
codex login status                    # "Logged in using ChatGPT" 확인
codex features list | grep image_generation   # image_generation 이 보여야 한다

실제로 겪은 문제: codex 전역 기본 모델(~/.codex/config.toml)이 ChatGPT 로그인에서 지원되지 않는 모델(2026-10-07에는 gpt-6.1-sol)로 바뀌어 있으면 이미지 생성이 400 오류로 실패한다. 전역 설정은 건드리지 말고, 실행할 때만 CODEX_MODEL=gpt-6-sol 처럼 지정한다(02_task2_weekly_event_run.md 6절).

7. GitHub CLI — 과제 1 웹서비스 배포

brew install gh
gh auth login            # GitHub.com → HTTPS → 브라우저 로그인
gh auth status           # repo · workflow 권한이 있어야 한다

8. 점검 명령 — 모두 통과하면 준비 끝

claude --version
ls CLAUDE.md .claude/agents .claude/skills
./.venv/bin/python -c "import google_play_scraper, playwright; print('python ok')"
./.venv/bin/python -c "import PIL; print('pillow ok')"
codex login status
codex features list | grep image_generation
gh auth status

Claude Code 안에서도 확인한다.

/agents          ← 7개 에이전트가 보이는지

스킬까지 한 번에 확인하려면 Claude Code에 이렇게 묻는다.

이 프로젝트의 하네스 점검해줘. CLAUDE.md, .claude/agents, .claude/skills 목록과 venv·codex·gh 상태를 확인하고 빠진 것을 알려줘.
점검이 실패하면 조치
codex login status 미로그인 Claude Code 안에서 ! codex login 을 입력하면 그 자리에서 로그인할 수 있다
gh auth status 실패 ! gh auth login
/agents 에 에이전트가 안 보임 Claude Code를 다시 시작한다. 같은 세션에서 막 만든 에이전트는 다음 세션부터 이름으로 불린다
