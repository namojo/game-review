실행 가이드 — Claude Code 하네스로 세 과제를 직접 돌리는 방법

썬더게임즈 실무자가 그대로 따라 할 수 있게 쓴 실행 안내서다. 프롬프트는 모두 코드 블록에 있어 복사해 붙여 넣으면 된다.

순서 문서 누가 내용
0 00_setup.md 처음 한 번, 담당 PC마다 Claude Code 설치·로그인, 하네스 복사, 플러그인, Python venv, codex·gh 로그인, 점검 명령
1 01_build_harness_prompts.md 하네스를 새로 만들거나 고칠 때 전체 3과제·과제별 하네스 구성 프롬프트, 좋은 프롬프트의 요소, 확인 항목, /harness:evolve 개선 요청
2 01_task1_review_run.md 운영(매일) "리뷰 데이터 갱신해줘", 누적 병합 명령, 검수 화면, 답변 등록, 재배포, 운영 전환 요약
3 02_task2_weekly_event_run.md 운영·디자인(매주) 3주 전 제작 일정표, 단계별 프롬프트, 검수 체크리스트, 수동 명령, 실제로 겪은 문제, 예약 실행
4 03_task3_ads_run.md 마케팅 샘플 실행, 실데이터 연결 뒤 프롬프트, 리포트 검증기, 예약 실행
