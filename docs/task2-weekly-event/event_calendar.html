근거가 더 좋은 대안이 있었는가

검토한 대안은 "광고 없는 주말" 단독 이벤트다. 광고 피로 해소 효과만 보면 가장 직접적이다. 하지만 이 안은 세 가지가 약하다. 스토어 프로모션 콘텐츠 가이드라인은 상시 프로그램이나 일반적인 기능 설명을 프로모션 대상으로 받지 않는다. 시즌 검색 수요도 없다. 매주 반복하면 광고 수익이 크게 흔들린다. 그래서 할로윈 안에 주말 2일짜리 "광고 없이 받는 할로윈 버프"로 넣었다. 리뷰 근거는 그대로 살리고, 광고 수익 영향은 2일로 묶어 측정한다.
