ROI 계산 방식

모든 값에 출처 유형을 붙인다: [실측] 이 프로젝트에서 데이터로 확인, [고객] 고객이 알려준 값, [가정] 컨설턴트 가정(근거 한 줄).

과제 1 — 리뷰 대응

항목 값 출처
일평균 리뷰 수(텍스트 있는 리뷰, 대표작 1종, 전 언어) stats.per_day_avg (약 6.3) [실측] 60일 수집
현재 1건 처리 시간 2분 [고객]
자동화 후 1건 검수 시간 맞춤 0.5분 / 템플릿 0.2분 [가정] 읽기·승인만
템플릿 대상 비율 make_batches 결과(약 40%) [실측]
  • 연간 절감 시간 = 일평균 × 365 × (2 − 가중 평균 검수 시간) / 60
  • 정성 효과(수치화하지 않고 근거만 제시): 맞춤 답변 비율, P1 24시간 대응, 주간 부서별 이슈 리포트, 다국어 번역 대기 제거
  • 비용: Claude API 사용료(월 리뷰 수 × 건당 토큰). 계산 시점에 claude-api 스킬로 최신 단가를 확인하고 산식과 함께 적는다.

과제 2 — 주간 이벤트 제작

항목 값 출처
현재 운영 시간 주 1~2시간 [고객]
현재 디자인 시간 주 1~2일(8~16시간) [고객]
자동화 후 운영 주 0.5시간(주제 승인·문구 검수) [가정]
자동화 후 디자인 주 2~4시간(키아트 선택·보정·최종 검수) [가정]
키아트 생성 시간 3규격 병렬 약 3분 [실측]
  • 주간 절감 = (운영 현재 − 이후) + (디자인 현재 − 이후) → 범위(최소~최대)로 제시
  • 연간 = 주간 × 52

과제 3 — 광고 운영·분석

항목 값 출처
현재 매일 1시간 이상 [고객]
자동화 후 매일 10~15분(리포트 읽기·제안 승인) [가정]
근무일 연 250일 [가정]
  • 연간 절감 = (60 − 12.5) × 250 / 60
  • 낭비 예산 조기 차단 효과는 실제 지출 데이터가 없으므로 금액으로 쓰지 않는다. "피로 소재·추적 누락을 하루 안에 발견"처럼 메커니즘으로만 설명한다.

표기

  • 합계는 "연간 약 N~M시간(FTE 약 x명분)"처럼 범위로 쓴다. FTE 1명 = 연 1,920시간(가정).
  • 인건비 환산이 필요하면 고객이 시간당 비용을 알려준 뒤에 계산한다. 임의 단가를 쓰지 않는다.
