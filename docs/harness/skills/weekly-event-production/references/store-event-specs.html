스토어 이벤트 규격과 copy.json 구조

규격은 2026-10 기준 공개 문서·업계 가이드로 확인했다. 제출 직전에 Play Console·App Store Connect 화면의 표시 한도를 한 번 더 확인한다(정책이 바뀔 수 있다).

Google Play — 프로모션 콘텐츠(LiveOps)

필드 한도·규격 비고
이벤트 유형 이벤트 / 혜택 / 주요 업데이트 등 주간 이벤트는 "이벤트"
태그라인(제목) 80자 이벤트 고유의 가치를 한 줄로. 과장 표현·대문자 남발 금지
설명 100~500자 권장 기간, 참여 방법, 보상 성격
이미지(가로) 1920×1080 (16:9) — 글자 금지(로고·슬로건·이벤트명 포함) 안전 영역: 위 15%, 좌우 10%, 아래 20% 안에 핵심 피사체를 두지 않는다
이미지(정사각) 1:1 정사각 — 필수 글자 없는 keyart_1x1.png 를 제출한다
승인·피처링 승인 최대 4일, 피처링 요청은 시작 14일 전까지 주간 이벤트는 3주 앞서 제작해야 피처링 기회를 잡는다
기간 시작·종료 일시 검토 기간을 고려해 시작 최소 며칠 전 제출
딥링크 선택 이벤트 화면으로 바로 이동

공식 가이드: support.google.com/googleplay/android-developer/answer/12929944 , Google Play promotional content guidelines(PDF).

App Store — 인앱 이벤트

필드 한도·규격 검색 색인
이벤트 이름 30자 O
짧은 설명 50자 O
긴 설명 120자 X
이벤트 카드 미디어 1920×1080 (16:9) —
이벤트 상세 페이지 미디어 1080×1920 (9:16) —
배지 Challenge / Competition / Live Event / Major Update / New Season / Premiere / Special Event 주간 이벤트는 보통 Special Event 또는 Challenge
기간 이벤트는 최대 31일, 게시는 시작 최대 14일 전부터
  • 미디어에 글자를 넣지 않는다. 이벤트 이름·설명은 스토어가 따로 표시하므로 겹쳐 보인다. 그래서 글자 없는 키아트 원본을 제출한다.
  • 이름과 짧은 설명은 검색 색인 대상이다. 게임명 핵심어(예: 원시인, 공룡, 방치형)를 자연스럽게 넣으면 ASO 효과가 있다.
  • App Store Connect API로 생성·현지화를 자동화할 수 있다(appEvents, appEventLocalizations, appEventScreenshots).

copy.json 구조 (단일 원천)

{
  "event_id": "2026-w44-halloween",
  "accent": "#ff7a1a",
  "period": { "start_kst": "2026-10-26T00:00+09:00", "end_kst": "2026-11-01T23:59+09:00" },
  "locales": {
    "ko": {
      "banner": { "title": "형님들의 할로윈 대작전", "subtitle": "호박 공룡을 사냥하고 한정 토템을 받아라!",
                  "period": "10.26 – 11.01", "badge": "기간 한정" },
      "notice": { "title": "...", "body": "..." },
      "push": ["...", "..."],
      "play": { "tagline": "...", "description": "..." },
      "appstore": { "name": "...", "short": "...", "long": "..." }
    },
    "en": { "...": "..." }
  }
}
  • 배너 title 은 짧을수록 좋다(ko 12자, 라틴 문자 28자 안팎). 길면 합성 스크립트가 글자를 줄여 가독성이 떨어진다.
  • 한·중·일 제목은 원하는 위치에서 \n 으로 줄을 나눌 수 있다.
  • 글자 수 검사는 공백 포함 기준이다. store_submission.md 에 필드별 실제 글자 수와 한도를 함께 적는다.
