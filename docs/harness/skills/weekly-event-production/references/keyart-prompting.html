키아트 프롬프트 구조

왜 이 구조인가

  • 글자 없음: 이미지 모델은 다국어 글자를 자주 틀리게 그리고, 언어마다 다시 그리면 비용이 언어 수만큼 늘어난다. 키아트는 한 번만 만들고 글자는 compose_banner.py 로 얹는다.
  • 화풍 고정: 첨부한 게임 스크린샷의 화풍을 매번 같은 문장으로 묘사한다. 주마다 화풍이 흔들리면 브랜드가 흐려진다.
  • 문구 여백: 규격마다 글자가 들어갈 자리를 비워 둔다. 합성 스크립트의 문구 위치와 맞춘다.

화풍 고정 문장 (그대로 붙여 쓴다)

첨부한 게임 이미지와 같은 화풍: 한국 웹툰·코믹북 스타일, 굵고 거친 잉크 외곽선, 선명한 셀 셰이딩, 과장된 표정. 주인공은 근육질 대머리 원시인 "형님"(가죽 허리옷, 맨발, 진지하지만 웃긴 표정). 공룡은 사실적인 비율에 코믹한 표정. 배경은 울창한 원시 정글. 채도 높은 색, 역동적인 구도, 모바일 게임 프로모션 일러스트 품질. 회화풍·유화풍·3D 렌더가 아니라 평면적인 셀 셰이딩 만화 채색.

규격별 구도

규격 생성 비율 최종 크롭 문구 여백(compose_banner.py 위치와 일치) 주 피사체 위치
16:9 가로 (keyart_16x9.png) 가로형 3:2 1920×1080 (위아래 약 8% 잘림) 왼쪽 52% 어둡고 단순하게 오른쪽 48%
9:16 세로 (keyart_9x16.png) 세로형 2:3 1080×1920 (좌우 약 8% 잘림) 위쪽 48% 하늘·단순 배경 아래쪽 52%
1:1 정사각 (keyart_1x1.png) 정사각 1080×1080 아래쪽 56% 지면·단순 배경 위쪽 44%

여백 값은 compose_banner.py 로 13개 언어를 합성해 잰 실제 문구 영역이다(16:9 가로 5~51%, 9:16 세로 6~48%, 1:1 세로 44~93%, 2026-10 planner 실측). 스토어 제출용으로도 쓰므로 Google Play 안전 영역(위 15%·좌우 10%·아래 20%) 안쪽에 핵심 피사체를 둔다.

모델이 만든 해상도를 background-size: cover 로 잘라 쓰므로, 머리·꼬리 같은 중요한 부분이 가장자리 8% 안에 있지 않게 "가장자리에 여유를 두고"를 넣는다.

프롬프트 틀

[규격] 가로형 3:2 비율 / 세로형 2:3 비율 / 정사각형
[화풍] (위 화풍 고정 문장)
[장면] {이벤트 테마를 형님과 공룡의 행동으로 표현 — 한 문장의 명확한 상황}
[테마 요소] {시즌 소품 3개 이하 — 예: 호박 등불, 보름달, 박쥐}
[색·조명] {테마색} 중심, 강한 역광/림라이트
[구도] 주 피사체는 {위치}. {여백 위치}는 어둡고 단순한 배경으로 비워 문구 자리로 쓴다. 가장자리에 여유를 둔다.
[금지] 글자, 숫자, 로고, 워터마크, UI 요소, 말풍선

비용·시간 (2026-10 실측)

  • 참고 이미지 2장 첨부 시 1장당 약 2분 30초, codex 토큰 약 12만. 3규격 병렬 생성은 약 3분이다.
  • 참고 이미지는 2장이면 충분하다. 더 붙이면 토큰만 늘어난다.
  • 실측 예: 첨부 shot1·shot2 + "할로윈 밤 정글, 호박 머리 티라노와 대치, 왼쪽 40% 비움" → 1536×1024, 문구 여백이 정확히 비었다. 다만 화풍이 게임보다 회화적으로 나와 "평면 셀 셰이딩" 문장을 추가했다.

실패 대응

  • 로그에 model is not supported when using Codex with a ChatGPT account → codex 전역 설정의 기본 모델이 ChatGPT 로그인에서 지원되지 않는다. 사용자 전역 설정을 고치지 말고 CODEX_MODEL=<지원 모델> 로 그 실행만 지정한다(2026-10-07: gpt-6-sol 성공).
  • [ok] 는 시작 시각 이후 새로 만들어진 파일만 뜻한다. 재생성 전 파일을 attempts/ 로 옮겨 두면 결과 비교가 쉽다.

검수 체크리스트

  • [ ] 글자처럼 보이는 낙서·간판이 없다
  • [ ] 문구 여백이 실제로 비어 있다(합성해 보면 바로 보인다)
  • [ ] 형님의 생김새가 게임 이미지와 비슷하다(대머리, 근육, 가죽 허리옷)
  • [ ] 특정 국가에서 민감한 상징(종교 상징, 국기, 실존 인물)이 없다
  • [ ] 세 규격이 같은 이벤트로 보인다(같은 색·소품)
