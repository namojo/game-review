화면 명세

사용자: 썬더게임즈 운영 담당자 1~2명. 하루 한 번 열어서 쌓인 리뷰를 처리한다. 한국어 UI.

전역

  • 상단 바: 앱 아이콘(Play 아이콘 URL 사용 가능) · 게임명 · 수집 기준 시각 · 탭(대시보드 / 검수 인박스 / 운영 가이드 / 설정)
  • 해시 라우팅(#/inbox, #/inbox/{id})으로 새로고침해도 위치를 유지한다.
  • 라이트·다크 모드 모두 지원(prefers-color-scheme + 수동 토글).
  • 390px 모바일 폭에서도 쓸 수 있어야 한다(목록 → 상세 전환형).

1. 대시보드

목적: "이번 주 리뷰에서 무슨 일이 있었나"를 30초 안에 파악한다.

  • KPI 카드: 전체 리뷰 / 스토어 미답변 / P1(즉시 대응) / 고객센터 이관 / 평균 별점 / 예상 절감 시간
  • 절감 시간 = 리뷰 수 × (2분 − 검수 0.5분). 계산식을 카드 아래 작은 글씨로 보여준다(가정값을 숨기지 않는다).
  • 차트(가벼운 라이브러리 1개 또는 SVG 직접 작성):
  • 일별 리뷰 수 + 평균 별점 추이
  • 유형 분포(가로 막대, 유형별 평균 별점 표시)
  • 언어·스토어 분포
  • "부서별 전달 목록": route_to 별(고객센터·개발·BM·기획)로 summary_ko 상위 항목을 묶어 보여준다. 운영팀이 주간 회의에 그대로 가져갈 수 있게 한다.
  • "현재 템플릿 vs AI 맞춤 답변" 예시 3건(부정 리뷰 위주) 비교 카드.

2. 검수 인박스 (핵심 화면)

목록(왼쪽) - 정렬 기본값: P1 → P2 → P3, 같은 등급 안에서는 검수 필요(needs_human) 먼저, 그다음 최신순. needs_human 을 등급보다 앞에 두면 의미 불명 P3 가 결제·접속 불가 P1 보다 위에 온다 - 필터: 처리 상태(검수 대기 / 승인 / 보류 / 등록 완료 / 전체), 스토어 미답변만, 스토어, 언어, 별점, 유형, 우선순위, 텍스트 검색(원문+번역) - 각 행: 별점, 유형 칩, 우선순위 표시, 언어 배지, summary_ko(없으면 원문 일부), 상대 시간

상세(오른쪽) - 원문(+ App Store 제목), 한국어 번역(접기 가능), 메타: 스토어·국가·버전·작성일·도움돼요 수 - 분류 칩: 유형·감정·우선순위·담당 부서·flags. 분류를 수동으로 바꿀 수 있다(로컬 저장). - AI 답변 초안 편집창(원문 언어) + 실시간 글자 수(Google Play 350자 한도 초과 시 빨간 경고, 승인 버튼 비활성화) - 답변 한국어 번역(reply_ko) — 편집하면 "번역이 원문 수정 전 기준"이라는 표시 - 기존 운영 답변이 있으면 나란히 비교 - 버튼: 승인(A) / 보류(H) / 템플릿 삽입 / 복사 / Claude로 다시 쓰기(BYOK 설정 시) / 등록 완료 표시 - 키보드: J·K 이전/다음, A 승인, H 보류, C 복사, / 검색

일괄 처리 - "P3 템플릿 답변 일괄 승인" — 확인 대화상자 없이 실행 취소(Undo) 토스트로 처리한다(브라우저 confirm() 금지). - 내보내기: 승인된 답변을 JSON·CSV로 다운로드. 필드: store, source_review_id, lang, rating, reply, approved_at, edited(bool). pipeline/post_replies.py 가 이 JSON을 그대로 읽는다.

3. 운영 가이드 탭

정적 설명 페이지. 현재 방식(AS-IS) → 자동화(TO-BE) 흐름도, 단계별 역할(자동/사람), 운영 전환 체크리스트(서비스 계정, API 키, 스케줄, 알림), 데이터 출처와 한계(공개 데이터 기반 PoC, App Store RSS는 국가별 최근 리뷰만).

4. 설정

  • Claude API 키 입력(BYOK) · 모델 선택 · 키 삭제. 키는 이 브라우저 localStorage 에만 저장된다는 안내.
  • 답변 톤 옵션(기본 / 더 짧게 / 더 공손하게) — 재생성 프롬프트에 반영
  • 검수 상태 초기화, 상태 백업(JSON 내보내기/가져오기)

BYOK 재생성 요청

POST https://api.anthropic.com/v1/messages, 헤더 x-api-key, anthropic-version: 2023-06-01, content-type: application/json, anthropic-dangerous-direct-browser-access: true. 시스템 프롬프트에 reply-guidelines 핵심(페르소나·350자·금지 사항)과 해당 언어의 템플릿 예시를 넣고, 응답은 JSON(reply, reply_ko)으로 받는다. 실패하면 오류 메시지를 토스트로 보여주고 기존 초안을 유지한다.

새 리뷰 붙여넣기

설정 화면 또는 인박스 상단에서 리뷰 원문을 붙여넣으면(BYOK 필요) 분류·번역·초안을 만들어 인박스 맨 위에 임시 항목으로 추가한다. 스토어 API가 없는 상황(예: 커뮤니티 글)에서도 쓸 수 있게 한다.

접근성·품질

  • 색만으로 상태를 구분하지 않는다(아이콘·텍스트 병기). 대비 4.5:1 이상.
  • 380건이 즉시 필터링되어야 한다(가상 스크롤 불필요, DOM 재사용 정도로 충분).
  • 데이터 로드 실패 시 원인과 해결 방법을 화면에 보여준다(예: file:// 로 열면 fetch 가 막힌다 → 로컬 서버 안내).
