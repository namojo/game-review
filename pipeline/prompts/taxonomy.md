# 리뷰 분류 체계

방치형 RPG 「원시인 형님들 키우기」의 실제 리뷰(2026-08~10, 378건)를 보고 정했다. 유형은 **누가 무엇을 해야 하는가**로 나눈다. 감정만으로 나누면 운영 조치로 이어지지 않기 때문이다.

## category (하나만 고른다)

| 값 | 의미 | 대표 표현 | 기본 route_to | 기본 priority |
|---|---|---|---|---|
| `praise` | 칭찬·응원·추천 | 재밌어요, 갓겜, good, muito bom | none | P3 |
| `ads` | 광고 빈도·강제 광고·광고 보상 불만 | 광고 3개씩, 광고 너무 많음, too many ads, реклама | bm | P2 |
| `monetization` | 과금 유도·가격·BM 불만(결제 오류는 아님) | 현질 유도, 돈독, pay to win, rubies 무료 획득 불가 | bm | P2 |
| `purchase_issue` | 결제 후 미지급, 광고 제거 미적용, 가격 표시 오류, 환불 요청 | 현질했는데 안 들어옴, 광고제거 적용 안 됨, 0원 표시 | cs | **P1** |
| `bug` | 오류·크래시·진행 불가·화면 깨짐 | 튕겨요, 멈춤, 버그, crash | dev | P1(진행 불가)/P2 |
| `account` | 계정·데이터 분실·복구·기기 변경 | 계정 찾을 수 있나요, 데이터 날아감 | cs | **P1** |
| `reward_issue` | 보상·이벤트·출석 보상 미지급 | 문명15 달성했는데 보상 안 됨 | cs | P1/P2 |
| `balance` | 난이도·성장 정체·밸런스·콘텐츠 소진 | 35000스테 이후 진행 어려움, 엔딩이 없음 | planning | P2 |
| `content_request` | 기능·콘텐츠 건의(불만 아님) | 자동클릭 패시브로, 새 문명 추가 | planning | P3 |
| `performance` | 발열·로딩·배터리·최적화 | 렉, 느려요, lag | dev | P2 |
| `other` | 의미 없는 문자열, 판단 불가, 게임과 무관 | ㅅ디늣ㄷㄴㄷ, 광고(한 단어만) | none | P3 |

**혼합 리뷰**: "재밌는데 광고가 너무 많아요" → 조치가 필요한 쪽(`ads`)을 고르고 `sentiment: "mixed"`. 별점은 참고만 한다. 별점 5점이라도 결제 오류를 말하면 `purchase_issue` 다.

**한 단어 부정 리뷰**("광고", "별로"): 내용이 있으면 해당 유형(`ads`), 정말 판단할 수 없으면 `other`.

## priority

| 값 | 기준 | 답변 목표 시간 |
|---|---|---|
| P1 | 돈·계정·진행 불가. 방치하면 환불·이탈·평점 하락으로 바로 이어진다 | 24시간 안 |
| P2 | 불만·버그·밸런스. 답변 품질이 평점 회복에 영향을 준다 | 48~72시간 |
| P3 | 칭찬·건의·무의미 | 주간 일괄 처리 가능 |

## route_to — 답변 외에 이 리뷰를 누가 봐야 하는가

`cs`(고객센터 확인 필요), `dev`(개발 버그 트래킹), `bm`(사업·수익화 담당 — 광고·과금 피드백 집계), `planning`(기획 — 밸런스·콘텐츠), `none`.

## needs_cs

사용자 계정이나 결제 내역을 직접 조회해야만 해결되면 `true`. `purchase_issue`, `account` 는 항상 `true`, `reward_issue` 는 대부분 `true` 다.

## flags (해당하는 것만)

| 값 | 언제 |
|---|---|
| `refund_request` | 환불을 명시적으로 요구 |
| `legal_threat` | 신고·소송·소비자원 언급 → 사람이 반드시 검수 |
| `profanity` | 욕설·비하 표현 |
| `minor_user` | 아이·학생 사용자로 보임(결제 관련이면 특히 주의) |
| `spam` | 광고·무관한 링크·도배 |
| `competitor_mention` | 경쟁 게임 언급 |
| `personal_info` | 리뷰에 전화번호·이메일·계정 ID 등 개인정보 노출 → 답변에서 절대 반복하지 않는다 |
| `update_related` | 특정 업데이트·버전 이후 문제라고 언급 |
| `needs_human` | confidence < 0.6, 또는 답변이 민감해 사람이 직접 써야 함 |
